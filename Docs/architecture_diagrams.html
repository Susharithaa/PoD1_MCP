Frontend SPA (React 18 + Vite)
Pages for chat/doc/manual API creation, HITL validator, registry browser, and ChatGPT hub. Global state via AuthContext, UploadContext, ThemeContext, LanguageContext. Data sync via TanStack React Query + Axios.
FastAPI Backend (port 8000)
5 router groups: auth, social_auth, agent, registry, chatgpt, monitor, subscription. JWT middleware, rate limiting via slowapi, async throughout with HTTPX for outbound HTTP.
Agent Pipeline (State Machine)
11-state machine: INIT → CLASSIFYING → PARSING → SCHEMA_GENERATING → RECONCILING → CONFIDENCE_SCORING → HITL_PENDING → VALIDATING → API_TESTING → SAVING → SAVED. Orchestrator coordinates all agents, handles retries, merges human edits.
Tool Execution Engine
Server-side proxy for ChatGPT tool calls. Parallel asyncio.gather execution. Retry with exponential backoff (2 retries, 0.5s base delay). Auth (API key/Bearer/Basic/OAuth2) injected only at execution time. 15s timeout per call.
LLM Client
AsyncOpenAI wrapper for GPT-4o. Supports chat() and chat_json() (enforced JSON mode). MOCK_LLM flag for offline development. Token usage tracked per request.
Data Layer
SQLAlchemy 2.0 ORM. SQLite for dev, PostgreSQL for production. Alembic migrations. JSON/JSONB columns for flexible schema storage. user_id indexes on all tenant tables for isolation.

Three User-Facing Flows
1. API Creation: Upload doc or chat → AI pipeline → HITL review → API saved to registry.
2. ChatGPT Integration: Connect API → GPT-4o loops tool calls → Tool executor proxies to real APIs → synthesized response.
3. Auth: Register/OTP login or Google/GitHub OAuth2 → JWT issued → all endpoints protected.
Security Boundaries
Credentials are AES-256 encrypted in DB and decrypted only inside ToolOrchestrator at execution time. JWT secures all API calls. OTP 2FA for local auth. CORS restricts browser origins. Rate limiting on sensitive endpoints.
Scalability Notes
In-memory ContextLayer designed to be swapped with Redis. SQLite swappable to PostgreSQL via DATABASE_URL. Agent sessions are resumable — HITL allows long-running workflows. Parallel tool execution via asyncio.gather.
Data Flow Highlights
Doc/text → ParsingAgent chunks → SchemaAgent OpenAPI schema → ReconciliationAgent merges → ConfidenceAgent scores → HITL UI → human edits merged → Validator + TestAgent → ApiSaver persists → registry exposed as OpenAI tools.
