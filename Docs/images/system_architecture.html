GPT-4o GPT-4o TOOL ENGINE — ChatGPTHub Feature v2 subscription gate
Subscription Gate v2
Checks User.chat_status:
 · none → 403 "chat_access:none"
 · pending → 403 "chat_access:pending"
 · rejected → 403 "chat_access:rejected"
 · approved + credits=0 → 402
Admins bypass gate entirely.
Context Layer
Per-session conversation history.
Build system prompt from connected APIs.
Inject last N turns as messages.
Auto-expire idle sessions (2 h).
Keyed by session_id in-memory.
Tool Orchestrator
Translate ApiDefinition → OpenAI tool schema.
Execute tool_calls via asyncio.gather().
Retry with backoff on failure.
Log to tool_call_logs table.
Return results to GPT-4o for next turn.
Cost formula (GPT-4o):  cost = (prompt_tokens × $2.50 + completion_tokens × $10.00) / 1,000,000   ·   Deducted from User.credits after full agentic loop   ·   Logged to token_usage table (user_id · session_id · cost_usd)
